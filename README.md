**Local-first personal operating system**

**Version:** 1.0.0 · **Year:** 2026 · **Status:** ACTIVE

## Overview

A modular personal OS dashboard that centralizes tasks, projects, finances, trading logs, calendar, learning, Pomodoro sessions, and notifications into one Zustand-backed, localStorage-persisted workspace.

## Architecture

The codebase follows a component-based architecture with typed domain models and service abstractions ready for backend integration. See the `docs/`, `src/`, or `app/` directories for the module structure.
